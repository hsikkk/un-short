# Screenshot Guide

Add your app's smartphone screenshots to this directory.

## Requirements

- **Minimum**: 2 screenshots
- **Maximum**: 8 screenshots
- **Size**: 320-3840px (portrait or landscape)
- **Format**: PNG or JPG

## File Naming

Use numeric prefixes to control display order:

```
1_main_screen.png
2_blocking_screen.png
3_settings.png
4_statistics.png
```
