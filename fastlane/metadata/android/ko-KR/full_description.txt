🚫 쇼츠 중독에서 벗어나세요

un:short는 유튜브 쇼츠, 인스타그램 릴스 등 짧은 영상 콘텐츠의 무한 스크롤을 차단하여 의도적인 콘텐츠 소비 습관을 만들어주는 앱입니다.

✨ 주요 기능

• 🎬 자동 차단: YouTube Shorts, Instagram Reels 등 자동 감지 및 차단
• ⏱️ 30초 대기: 충동적 소비를 막는 쿨다운 타이머
• 🤔 질문 던지기: "정말 지금 봐야 할까요?" 스스로에게 묻기
• 📊 사용 통계: 차단 횟수와 절약한 시간 확인

🔍 접근성 서비스 사용 안내

이 앱은 Android의 AccessibilityService API를 사용하여 YouTube Shorts와 Instagram Reels 같은 짧은 영상 콘텐츠에 접근하는 것을 자동으로 감지합니다. 이 권한은 다음 핵심 기능을 제공하기 위해 필수적입니다:

• 쇼츠 콘텐츠 화면 자동 감지
• 차단 화면 표시로 무의식적 소비 방지
• 30초 생각할 시간 제공

이 서비스는 오직 쇼츠 차단 목적으로만 사용되며, 다른 개인정보나 데이터에는 접근하지 않습니다.

🎯 왜 un:short인가요?

짧은 영상 콘텐츠는 중독성이 강합니다. 무의식적으로 앱을 열고, 시간 가는 줄 모르고 스크롤하게 됩니다. un:short는 이러한 무의식적 소비에 적절한 마찰(friction)을 추가하여:

• 30초의 생각할 시간 제공
• 질문을 통해 의도적 선택 유도
• 습관 패턴 단절

💡 사용 방법

1. 앱 설치 후 필요한 권한 허용
2. 백그라운드에서 자동으로 실행
3. 쇼츠 접근 시 자동으로 차단 화면 표시
4. 30초 동안 생각하는 시간을 가지기

🔒 개인정보 보호

• 모든 데이터는 기기 내에서만 저장
• 외부 서버로 전송되는 정보 없음
• 최소한의 권한만 요청

📱 주요 지원 앱

• YouTube (쇼츠)
• Instagram (릴스)
• 기타 짧은 영상 플랫폼
