# un:short 현재 제품 스펙

- 상태: Current
- 대상 버전: `1.9.0` (`versionCode 33`)
- 마지막 코드 대조: 2026-08-02
- 범위: 현재 저장소에 구현된 Android 앱 동작

이 문서는 현재 제품 동작의 단일 진입점입니다. 새 기능이 실제 제품에 포함되면 이 문서를 함께 수정합니다. 기능을 제안하거나 결정한 배경은 `documents/prd/`에 남기며, 구현 세부사항과 정확한 상수는 코드가 최종 기준입니다.

## 1. 제품 목적

un:short는 짧은 영상과 무한 피드 진입을 감지하고 의도적인 마찰을 제공해 충동적인 콘텐츠 소비를 줄이는 Android 앱입니다. 접근성 서비스로 대상 화면을 판별하고, 차단 화면·대기 타이머·폰 뒤집기·즉시 해제 정책을 적용합니다.

## 2. 지원 환경과 대상

- 플랫폼: Android `minSdk 26`, `targetSdk 35`
- Shorts/Reels 대상: `YouTube Shorts`, `Instagram Reels`, `Facebook Reels`, `Naver Shorts`, `TikTok Shorts`
- 홈 피드 대상(Beta): `Instagram`, `YouTube`, `Threads`, `Facebook`
- 홈 피드 Beta 기본 상태: `OFF`

지원 목록은 `AppBlockingRegistry.kt`와 `FeedTargetRegistry.kt`가 기준입니다. 대상 앱이 UI 구조나 접근성 View ID를 변경하면 감지가 일시적으로 부정확해질 수 있습니다.

## 3. 핵심 차단 동작

### Shorts/Reels

1. 사용자가 활성화한 대상 앱에서 Shorts/Reels 화면을 감지합니다.
2. 진입 방식과 세션 상태에 따라 차단 오버레이를 표시합니다.
3. 사용자는 그만 보기, 대기 후 계속 보기, 조건을 충족한 즉시 보기 중 가능한 행동을 선택합니다.
4. 대기 흐름에서는 기기를 뒤집은 상태로 타이머를 진행하며 다시 세우면 진행을 멈춥니다.
5. 기본 대기 시간은 `30초`이고 설정에서 변경할 수 있습니다. 수면 시간에는 60초가 적용됩니다.

차단 전체 활성화와 앱별 활성화를 별도로 관리합니다. 외부 앱별 감지·미디어 제어·종료 방식은 `AppBlockingRegistry` 설정을 따릅니다.

### 홈 피드(Beta)

별도 접근성 서비스가 피드 화면과 스크롤 세션을 감지합니다. Beta 기능과 앱별 토글이 모두 켜진 대상에만 적용됩니다. 사용자는 차단 화면에서 그만 보거나 계속 보기를 선택할 수 있습니다.

## 4. 무료 및 프리미엄 정책

| 항목 | 무료 | 프리미엄 |
|---|---|---|
| 쇼츠 보조 버튼 활성화 지연 | `2초` | 즉시 |
| 피드 계속 보기 활성화 지연 | `5초` | 즉시 |
| 클릭 진입의 즉시 보기 | 일일 한도 차감 | 무제한 |
| 광고 | 정책에 따라 노출 | 프리미엄 정책에 따라 제외 |

Lifetime Premium은 유효한 프로모션 코드로 활성화할 수 있습니다. Google Play 결제 상태와 Lifetime 활성화 상태는 `PremiumManager`가 통합합니다.

## 5. 즉시 해제 한도

- 무료 사용자 일일 기본 한도: `10회`
- 즉시 보기 1회 사용: 한도 1회 차감
- 한도 소진 후 리워드 광고 1회 완료: 기본 `3회` 충전
- 프리미엄 사용자: 무제한, 차감 없음
- 초기화: 디바이스 로컬 날짜 기준 자정 리셋과 다음 조회 시 lazy 보정

일일 한도와 광고 충전량은 Firebase Remote Config 값으로 달라질 수 있습니다. 위 수치는 앱에 포함된 기본값입니다.

## 6. 사용자 설정

- 전체 차단 활성화
- 대상 앱별 차단 활성화
- 대기 시간과 햅틱
- 스크롤 이후 차단 정책
- 충동적 비활성화 방지와 일시 해제
- 수면 모드: 기본 비활성, 기본 시간 `22:00–06:00`
- 일일 사용 제한: 기본 비활성, 기본 한도 `60분`
- 차단 전후 사용자 메시지
- 바로 보기 버튼 표시 여부: 기본 ON. OFF 시 클릭 진입 차단 화면에서 버튼만 숨기며 일일 한도 잔여량은 보존
- 피드 차단 Beta 및 피드 앱별 활성화

## 7. 통계와 알림

- Shorts 세션, 실제 시청 여부와 시청 시간을 Room 데이터베이스에 기록합니다.
- 일별·시간대별 리포트를 제공합니다.
- 일일 리포트 알림, 차단 리마인더, 일일 제한 관련 알림을 지원합니다.
- Android 13 이상에서 알림은 런타임 알림 권한에 의존합니다.

## 8. 필수 권한과 시스템 통합

| 항목 | 목적 |
|---|---|
| 접근성 서비스 | 대상 화면과 스크롤 감지, 차단 흐름 제어 |
| 다른 앱 위에 표시 | 차단 UI 표시 |
| 알림 | 리포트, 리마인더, 제한 알림 |
| 사용 정보 접근 | 일일 사용량 모니터링 |
| 부팅 완료 수신 | 예약 작업과 상태 복구 |
| 기기 관리자(선택) | 제거 방지 기능 |

네트워크는 결제, 광고, 분석, Crashlytics, Remote Config 및 인앱 리뷰 연동에 사용됩니다.

## 9. 알려진 제약

- 접근성 서비스가 꺼지거나 필요한 권한이 회수되면 차단이 정상 동작하지 않습니다.
- Android 제조사 및 대상 앱 버전에 따라 접근성 이벤트와 UI 구조가 다를 수 있습니다.
- 완전한 시스템 수준 차단이 아니므로 사용자가 권한이나 앱 상태를 변경해 우회할 수 있습니다.
- 피드 차단은 Beta이며 외부 앱 UI 변경에 특히 민감합니다.
- Remote Config가 적용되면 이 문서의 기본값과 실제 운영값이 달라질 수 있습니다.
